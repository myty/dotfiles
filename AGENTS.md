# AGENTS.md

Nushell dotfiles. `README.md` covers layout and install; this file holds what the code doesn't say.

## Verify

- Parse-check with absolute paths: `nu -c 'nu-check --debug /abs/path/file.nu'`. Run from a script file, `nu-check` resolves relative paths against the script's directory, not the working directory.
- `config.nu` and `env.nu` source through `~/.config/dotfiles`, a symlink that `install.nu` creates. A fresh environment needs `nu install.nu` before the parse check passes. CI does this.
- `nu -c` skips `config.nu` and autoload scripts. Check startup behaviour in an interactive shell (`script -q /dev/null nu -e '...'` gives a pty).

## Nushell constraints

- `source` and `use` take parse-time constant paths. Optional files use `const X = (if (...| path exists) { $p } else { null })` then `source $X`. Closures can't appear in `const` values, so keep command lists as data (names and args).
- Target Nushell 0.117 and newer; use current command names (`str lowercase`, `$nu.home-dir`). Avoid `$env.HOME`, which Windows lacks.
- Startup order is `env.nu`, then `config.nu`, then vendor autoload (alphabetical). `env.nu` runs before mise has put tools on `PATH`; find mise-installed binaries with `mise which`.
- mise's `pre_prompt` hook rewrites `PATH` wholesale. `zz-path-priority.nu` (generated by `autoload.nu`) registers the PATH hook so it sorts after `mise.nu`.

## mise

`mise.toml` applies only inside this repo. Tools the shell calls by name from any directory belong in `mise/shell-tools.toml`, which `install.nu` links into `~/.config/mise/conf.d/` (merged into the global config). A tool in only `mise.toml` fails with "No version is set for shim" elsewhere.

## Cross-platform

Every change must work on macOS, Linux and Windows. Branch on `$nu.os-info.name`, and build paths with `path join`.

## Git

- Commits use Conventional Commits.
- Commit email is `myty@users.noreply.github.com`, set by an `includeIf` for `~/dev/github/myty/`. GitHub rejects pushes that expose another email.
- Pushing needs the `myty` GitHub identity. A parent `~/dev/github/myty/mise.toml` sets `GH_TOKEN`; outside an activated shell, run `mise x -- git push`.

## Don't edit

`nushell/nu_scripts` is a submodule of the `myty/nu_scripts` fork. Keep the fork identical to upstream so it always fast-forwards; the sync workflow lives in this repo for that reason.
